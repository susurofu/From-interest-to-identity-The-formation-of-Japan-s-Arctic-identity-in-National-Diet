# From Interest to Identity: The Formation of Japan's Arctic Identity in National Diet Discourse, 1949–2025

This repository contains supplementary materials, including data-processing pipelines used in the preparation of the article "From Interest to Identity: The Formation of Japan's Arctic Identity in National Diet Discourse, 1949–2025," accepted for publication in Polar Science.

The National Diet records are available in 北極-2025-09-30.csv.

The analysis is provided in Jupyter notebooks organized by the different time periods covered in the study.

Illustrations.ipynb contains the code used to generate the figures presented in the paper.

All data resulting from topic modeling are stored in folders corresponding to the respective time periods. Data used to create tables and figures are placed in the corresponding folders.

The Kokkai_tool folder contains a GUI application that allows users to collect data from the National Diet API and perform topic modeling using the methodology described in the referenced paper.
